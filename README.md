This code is for our article"CLVTNet: Efficient CNN-based Spatial Channel Enhanced Vision Transformer for Auditory Attention Detection Using EEG"
 
Architecture of CLVTNet for auditory attention detection. EEG signals are transformed into 2D spectro-spatial maps, and processed through a CNN-lightweight transformer encoder. A dual-branch feature extraction module integrates local (DConv) and global (MHSA, CTR) features, followed by fusion and hierarchical processing in the ViT encoder.
